## 📌 Projects Included

### 1. 🚢 Titanic Survival Prediction

**Project Type:** Classification

The Titanic Survival Prediction project aims to predict whether a passenger survived the Titanic disaster based on different passenger-related features.

The dataset contains information such as passenger class, gender, age, number of siblings/spouses, number of parents/children, fare, and port of embarkation.

### 🔹 Key Steps

* Data Loading and Exploration
* Data Cleaning and Preprocessing
* Handling Missing Values
* Feature Selection
* Categorical Data Encoding
* Exploratory Data Analysis
* Train-Test Split
* Machine Learning Model Training
* Prediction
* Model Evaluation

### 🔹 Features Used

* Passenger Class (`Pclass`)
* Gender (`Sex`)
* Age (`Age`)
* Number of Siblings/Spouses (`SibSp`)
* Number of Parents/Children (`Parch`)
* Fare (`Fare`)
* Port of Embarkation (`Embarked`)

### 🔹 Target Variable

`Survived`

* `0` → Did Not Survive
* `1` → Survived

### 🔹 Technologies Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Google Colab

## 💳 3. Credit Card Fraud Detection

**Project Type:** Classification

The Credit Card Fraud Detection project focuses on identifying whether a credit card transaction is **genuine or fraudulent** using Machine Learning classification techniques.

One of the major challenges in this project is the highly imbalanced dataset, where fraudulent transactions represent only a very small portion of the total transactions.

To address this issue, **SMOTE (Synthetic Minority Over-sampling Technique)** is used on the training data to improve the representation of the minority fraud class.

### 🔹 Key Steps

* Data Loading and Exploration
* Data Preprocessing
* Exploratory Data Analysis
* Feature Scaling
* Train-Test Split
* Handling Class Imbalance
* SMOTE
* Logistic Regression
* Random Forest Classification
* Prediction
* Model Evaluation
* Model Comparison

### 🔹 Dataset Information

* Total Transactions: 284,807
* Total Columns: 31
* Genuine Transactions: 284,315
* Fraudulent Transactions: 492

### 🔹 Target Variable

`Class`

* `0` → Genuine Transaction
* `1` → Fraudulent Transaction

### 🔹 Machine Learning Models

* Logistic Regression
* Random Forest Classifier

### 🔹 Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC Score
* Confusion Matrix

### 🔹 Technologies Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Imbalanced-learn | Google Colab
